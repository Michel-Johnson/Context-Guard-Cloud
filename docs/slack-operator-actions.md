# Slack 按钮代操作

Coordinator 使用当前已登录 Slack 用户的按钮操作能力，不要求用户再去客户端逐对话启用。`get_slack_actions` 从当前业务状态读取真实名称和版本，`perform_slack_action` 保存对应动作；Slack 宿主在模型轮次结束后执行原后端入口并返回短回执。

覆盖执行端启用、挂载与方案确认/退回、执行提示导出、通过独立测试后的结果验收/退回、已配置模型选择。项目目录、切换、地图读写和交流表情继续使用已有工具，不新增重复入口。

代操作记录包含真实操作者、原始请求、项目/对话、准确业务版本和 `performedBy: coordinator`，不是伪造用户点击。账号登录、实际设备注册、已通过的测试证据、版本一致性和明确撤销仍执行原业务校验；不把离线、未接收或未知结果显示为成功。原编号重放返回原回执，不再派发一次。

能力不等于本轮全部动作已经完成。执行端切换要先结束当前模型轮次；恢复业务协调仍沿原任务流程，不能把启用回执当作任务批准、执行或完成。普通机器人不会借用用户身份；它们的独立委托配置不受此入口修改。
